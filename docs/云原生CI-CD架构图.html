一、四台虚拟机分别装什么

上半是"工厂"（把代码变成镜像），下半是"运行现场"（把镜像跑成服务）。

二、一次 git push 之后发生了什么

Webhook 是整条链路的"开关"，Jenkinsfile 是流水线本身的剧本。

三、用户的请求怎么走进 Pod

外层 Nginx 是"小区门"，Ingress 是"单元门"，Service 是"楼层分发"。

四、六个阶段在练什么

每一阶段对应一块面试能讲的能力，不只是"装了个软件"。

阶段做什么练的能力
一系统初始化 + Ansible 批量运维Linux 基础自动化
二Harbor 私有仓库 + HTTPS 证书镜像管理TLS
三Flask 应用 + MySQL + 备份脚本容器化Shell 备份
四K8s 集群 + Calico + IngressK8s 编排网络
五Jenkinsfile + Webhook 全链路CI/CD流水线
六Prometheus + Grafana + 告警可观测性告警
